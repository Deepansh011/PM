# InboxIQ Demo Video Script (90–150 seconds)

**Target duration: ~120 seconds**

**0–15 seconds — Introduction**
“Hello, this is InboxIQ, our Prompt Engineering mini-project for problem C16. It helps staff triage emails by category and priority and drafts a reply for human review.”

**15–30 seconds — Input**
“Here I enter a fictional email about conflicting exam dates, select the sender role and academic-calendar context, and optionally provide an approved policy excerpt.”

**30–55 seconds — Prototype output**
“Here the system displays a category, priority, reason, summary, policy-grounding note, draft reply and review flags. The draft avoids inventing an official date and asks for confirmation when evidence is missing.”

**55–80 seconds — Prompt comparison**
“We compare a baseline prompt, a structured prompt and a refined prompt. The refined version adds explicit priority rules, few-shot examples, untrusted-email handling and human-review requirements.”

**80–105 seconds — Evaluation**
“We run the same labelled synthetic emails against each prompt version and record category accuracy, priority accuracy, JSON validity, reply quality and grounding. These are our actual results: [insert only measured results].”

**105–120 seconds — Limitations**
“The prototype does not send emails. The demo mode is heuristic-based; actual model results are measured separately. Future work includes stronger policy retrieval and more comprehensive testing.”

Before recording: run the app, use fictional data, capture real outputs, and replace every bracketed placeholder with evidence from your own run.
