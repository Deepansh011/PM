# Milestone 2 Submission Checklist — InboxIQ (C16)

Based on the course guideline categories:
- [ ] Prompt / solution design and diagram.
- [ ] Running prototype or meaningful partial implementation.
- [ ] Pilot run with representative inputs/outputs.
- [ ] Updated accessible Git repository or Drive folder.
- [ ] Technical report / synopsis / other appropriate document.
- [ ] 90–150 second short demo video.

Supporting evidence to prepare:
- [ ] Prompt versions V1, V2, V3.
- [ ] 50 synthetic labelled emails.
- [ ] Actual-results CSV from model runs.
- [ ] Evaluation summary and failure analysis.
- [ ] Screenshots of the working prototype.
- [ ] README and dependency/setup instructions.
- [ ] Individual contribution evidence if this is a team project.
- [ ] Verify official LMS instructions, accepted formats, and deadline.

Do not submit blank placeholders as completed evidence. Replace report placeholders only after testing.
